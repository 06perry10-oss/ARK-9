# ARK-9 RC3 — Completely Free

ARK-9 is a completely free Python desktop chat application.

## Free forever

ARK-9 has no paid plans, subscriptions, premium editions, license keys, or paid feature locks. Every feature included in the project is available to everyone at no cost.

- No payment required
- No account or license key required
- No premium or Pro tier
- No subscription
- No paid feature gates
- Runs locally with Python and Tkinter
- No API key required for the built-in chat responses

## Run

```bash
python ark9.py
```

Python 3 with Tkinter is required. Tkinter is included with many standard Python installations.
